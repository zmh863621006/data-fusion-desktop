# 02. 产品流程与 UI 规范

## 1. 设计定位

本产品是桌面业务工具，不设计成传统后台管理系统。核心体验是：少层级、强状态提示、围绕“系统登录 → 查询 → 本地回流 → 数据使用”展开。

视觉建议：深色侧边栏 + 浅色内容区 + 蓝色主色。减少大面积统计图和后台式菜单堆叠，突出当前系统、当前事项、登录状态、查询条件和同步状态。

## 2. 页面地图

```text
启动/激活
├─ 密钥激活页
└─ 授权异常页

工作台
├─ 首页
├─ 系统模块
│  └─ 系统主页
│     ├─ 系统登录
│     └─ 业务事项
│        ├─ 查询页
│        ├─ 查询结果预览
│        ├─ 同步确认
│        └─ 数据详情/历史轨迹
├─ 同步任务
├─ 本地数据中心
├─ 导出中心
├─ 日志中心
├─ 授权信息
└─ 设置
```

## 3. 密钥激活页

仅输入 License Key，不提供用户名/密码登录。

展示：
- 产品名称和版本
- 设备标识（脱敏展示）
- 密钥输入框
- 激活按钮
- 本地数据说明

激活成功后展示授权系统、有效期和设备状态，然后进入工作台。

## 4. 首页

首页不是“管理后台仪表盘”，而是操作入口。

重点区块：
- 最近使用系统
- 系统登录状态
- 最近同步任务
- 本地数据更新时间
- 快捷进入未办结事项
- 更新提醒

顶部全局搜索只搜索本地数据库，不直接访问业务系统。

## 5. 系统主页

例如“市场准入系统”。

顶部：
- 系统名称
- 插件版本
- 当前登录状态
- 登录/重新登录/退出系统按钮
- 最近会话检查时间

主体：业务事项卡片，例如企业设立、变更、注销等。

每个事项卡片展示：
- 本地数据量
- 最近同步时间
- 未办结数量（如果适用）
- 最近任务状态

## 6. 系统登录流程

登录不是本应用账号登录，而是原业务系统登录。

流程：

```text
进入系统
→ 检查 Session
→ 未登录
→ 打开该插件定义的登录 UI
→ 用户完成原系统认证
→ 插件获得有效 Session
→ UI 状态改为“已登录”
→ 自动返回之前操作
```

登录方式由插件决定：账号密码、验证码、扫码、统一身份认证、嵌入浏览器授权等。

## 7. 业务事项查询页

查询条件由 `QuerySchema` 动态生成，不把字段写死在主程序。

支持字段类型：
- 文本
- 数字
- 日期
- 日期范围
- 单选
- 多选
- 联动选择（后续）
- 远程字典（后续）

页面动作：
- 查询
- 重置
- 保存查询模板
- 同步到本地

如果 Session 失效，用户点击查询时先重新登录，登录成功后恢复原查询条件并继续。

## 8. 查询结果预览

“查询”与“写入本地”分开。

预览先展示原系统结果。同步前计算：

```text
原系统返回：1245
新增：126
更新：83
无变化：1036
```

用户确认后才 commit 到本地。

## 9. 同步确认页

清楚展示：
- 查询条件
- 数据范围
- 新增数
- 更新数
- 无变化数
- 可能冲突或异常数

支持查看变化明细。对于更新记录，可展开查看关键字段“旧值 → 新值”。

## 10. 数据详情页

左侧/主体展示当前最新数据；右侧展示状态历史时间轴：

```text
09-01 10:20 受理中
09-02 14:15 审批中
09-03 09:41 已办结
```

历史来源是本地每次同步捕获到的版本变化。

## 11. 同步任务中心

长查询统一作为任务执行，避免 UI 卡死。

任务状态：
- waiting
- running
- completed
- partial_failed
- failed
- cancelled

详情展示：
- 当前页/总页
- 已读取条数
- 已处理条数
- 新增/更新计数
- 重试次数
- 错误摘要

## 12. 本地数据中心

按最终数据使用场景组织，而不只按原系统页面组织。

筛选维度：
- 系统
- 业务事项
- 时间
- 状态
- 同步批次
- 关键字

支持动态列、保存视图、导出当前视图。

## 13. 设置页

仅提供工具级设置：
- 本地数据目录
- 下载/更新设置
- 日志级别
- 自动同步开关
- 导出默认目录
- 插件状态
- 数据备份/恢复（后续）

不出现“用户管理、角色管理、组织管理”等后台系统功能。
