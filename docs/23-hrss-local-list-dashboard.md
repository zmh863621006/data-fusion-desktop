### 人社串行执行与超时跳过

按用户最后确认，所有人社count/list、街道办办理记录、一次性扩岗、创业培训查询页面及列表共享同一串行队列，不设置固定等待间隔。同一时间仅执行一个人社业务事项的查询与保存，后续任务按顺序排队；等待中的任务可取消，前项失败也会释放后项，其他业务系统的并发设置不变。单次60秒超时，仅明确的网络/传输超时最多尝试5次（含首次）；取消、会话失效、参数或结构错误不重试。每次超时仅记录静态接口路径和尝试次数，不记录参数、凭据或业务数据。

达到五次上限后按用户要求跳过：失业count超时跳过该日，列表页超时继续已知后续页；其他列表首分页无法取得总数时跳过该来源，已知中间页则继续后续页；办理记录超时跳过该办件，不用空日志覆盖已保存的完整历史。任务保存成功取得的行，并持久化跳过次数与“结果含缺项”提示。大屏保留最近无超时跳过的成功快照并显示最新跳过数量，不把超时得到的0条当成真实0。

本轮相关离线回归及类型检查通过，包含串行无固定等待、业务事项排队与取消、60秒单次超时、5次封顶、恢复与取消、分页/办理记录继续执行、部分批次持久化及脱贫提示渲染；不为验证重试而向业务系统故意制造超时，不重跑整月。

## 登录、证书与会话

未登录入口使用用户确认的 `https://hrss.gdgov.cn/sso/login.html`，已验证会话的业务首页才使用原Java中的就业SSO service目的页面；两者分别维护。登录原站页面保留为应用标签。主进程从同分区成功请求中捕获 `Access-Token`；WGBT一次性扩岗业务单独捕获Cookie。多个监听规则一次注册，避免Electron同事件监听互相覆盖。令牌、Cookie与浏览器会话保存在系统账户加密存储，不发送到渲染页面或腾讯云后台。

不把旧后端的8小时Redis缓存时间当作源会话有效期。启动恢复后用当日失业count只读验证，网络问题与明确会话失效分别处理。扩岗仍需用户在原站打开一次该业务，以取得独立会话。

开发机只读握手发现原站内网证书链未受本机信任。1.0.15/1.0.16首次连接需要用户确认并加密保存该张证书指纹。用户于2026-11-04要求新客户端也自动确认后，1.0.17将这张已核验并获用户确认的证书SHA256固化在 `src/core/config/source-certificate-pins.ts`，首次连接即生效，无需每台机器再保存确认记录，也不弹出原生确认框。

例外仍只作用于人社独立分区及 `hrss.gdgov.cn` 主机的颁发机构不信任错误；必须匹配内置指纹、SAN和有效期。未核验的内网证书直接拒绝，不用历史手工记录放行，不自动学习新证书；更新信任列表需审查源码并更新客户端。其他域、证书过期、主机名错误和撤销错误继续交由Chromium正常拦截。不修改系统证书、不忽略全部TLS错误、不从远端加载任意信任规则。

## 本地持久化与导出

完整列表先进行幂等比对，再在一个事务中保存合并台账、历史版本及批次输出。取消检查放在提交前后；取消或保存异常会回滚。数据库连接将独立读写和事务串行排队，避免其他设置保存混入待回滚的事务。

新增SQLite索引 `idx_runtime_tasks_success_snapshot`，使用现有 `CREATE INDEX IF NOT EXISTS` 启动迁移，不重建或删除业务表。最近成功快照按系统/事项与完成时间直接查库，不受任务列表100条显示上限影响。

人社台账只读，页面默认脱敏姓名、证件与联系方式，可搜索、翻页、切换批次及导出。导出仅包含声明的中文业务列，不套行政许可模板、不执行双公示标红校验。文件名为 `业务台账-业务名-日期范围.xlsx`，无日期依据显示“全部列表”；保存到应用下的“导出文件”，导出路径可点击打开文件夹。

日期筛选待接入的任务和批次明确显示“所选日期，尚未生效，按原列表范围回流”。大屏覆盖期与导出文件命名不会使用这组待接入的选择；仅使用实际生效的查询日期或导出记录本身的日期。原求职创业补贴代码虽设置过 `bce089Start/bce089End`，新参数映射和实际服务端筛选效果在本轮均按用户要求暂缓，不以旧代码存在参数作为已验证生效的证据。

## 看板口径与授权

独立原生全屏窗口显示本地统计，Esc关闭并保留工作台。大屏每30秒重新读取本机数据，也可手动刷新，不发起任何源业务请求。

每个已授权事项只使用最近一个完成成功的批次；失败、取消和正在执行的批次不替换它。成功空批次为真实0，未回流为未知，明确标注查询日期和最后成功时间。合并台账保留历次记录，因此它与最近批次统计可能不同。

统计包括台账条数、成功覆盖事项数、列表状态、街道跟踪是/否/未知、互不重叠的年龄桶和有日期依据的列表滞留提示。优先使用列表年龄/出生日期，否则从合法18位证件号在主进程内推导；无效或脱敏证件为未知。不同事项可能有相同人员，不宣称为辖区就业总人数，不汇总未核实单位的金额。

72小时待处理、二审次月底后超过72小时待支付仅为列表滞留提示，不代表官方办理超期或工作日计算。缺时间/状态依据显示未知，未接入指标不填0。

主进程按当前签名授权再次过滤系统及事项；大屏仅返回聚合DTO，不返回姓名、证件、电话、原始地区或原始错误。普通渲染页面不能冒充专用大屏窗口；源站子页面不能调用本地看板IPC。
