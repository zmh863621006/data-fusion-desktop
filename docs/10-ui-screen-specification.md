# UI 页面规格（开发基线）

本产品是桌面工具，不是后台管理系统。应用本身无用户名/密码登录，首次使用及授权变化时仅处理 License 密钥。

## 1. 启动检查页
应用启动时自动执行，不要求用户操作：
- 本地配置初始化
- License 状态检查
- 数据库迁移
- 插件扫描与兼容性检查
- 上次异常任务恢复检查
- 可选的版本更新检查

异常需给出可理解的恢复动作，不能只显示技术堆栈。

## 2. 密钥激活页
出现条件：首次使用、无 License、License 过期或设备授权失效。

内容：
- 产品名称和版本
- 密钥输入框
- 激活按钮
- 本机设备标识摘要
- 授权说明
- 离线授权导入入口（预留）

激活成功后展示允许使用的系统、有效期等摘要，然后进入工作台。

## 3. 工作台首页
不是 BI 大屏。重点是“现在能做什么”：
- 已授权系统模块
- 各系统登录状态
- 最近同步任务
- 最近数据变更数量
- 本地数据总量摘要
- 最近失败任务
- 全局本地搜索入口

## 4. 系统模块页
每个系统一张卡片：
- 系统名称
- 插件版本
- 登录状态
- 最近查询/同步时间
- 业务事项数量
- 进入系统按钮

## 5. 业务系统首页
顶部固定展示系统状态：
- 未登录 / 登录中 / 已登录 / 会话即将过期 / 已失效
- 当前业务系统身份摘要（如系统允许获取）
- 重新登录 / 退出系统

主体展示该系统下所有业务事项卡片。

## 6. 系统登录页/窗口
这不是本软件账号登录，而是目标业务系统自己的登录流程。

根据插件能力可采用：
- 原生表单
- 独立 BrowserWindow
- SSO 跳转
- 扫码
- 手机验证码

成功后关闭登录窗口并继续用户原先操作。原始 Token/Cookie 不展示给 Renderer。

## 7. 业务事项查询页
结构：
1. 面包屑：系统 / 事项
2. 登录状态
3. Schema 动态生成的查询条件
4. 查询按钮
5. 保存查询模板（后续）
6. 查询结果区

未登录时点击查询：自动进入系统登录；成功后恢复原查询条件继续执行。

## 8. 查询进度/任务页
长查询不能阻塞 UI。展示：
- 当前任务状态
- 当前页/时间区间
- 已获取条数
- 总量（若系统返回）
- 当前重试次数
- 取消按钮
- 错误信息

## 9. 查询结果预览页
查询结果先预览，不默认落库。

展示：
- 原系统返回总数
- 当前页数据
- 字段列配置
- 本地比对按钮 / 回流到本地按钮

## 10. 回流确认页
Sync Engine 比对完成后明确展示：
- 本次总数
- 新增数量
- 更新数量
- 无变化数量
- 异常/缺少唯一键数量（后续）

用户确认后才执行 commit。

## 11. 本地数据中心
数据来源仅为本地数据库：
- 系统筛选
- 事项筛选
- 时间筛选
- 状态筛选
- 全局关键字
- 动态列
- 保存视图（后续）
- 导出

## 12. 单条数据详情
展示最新完整记录，并提供：
- 字段详情
- 来源系统/事项
- 首次获取时间
- 最近更新时间
- 状态历史时间轴
- 历史版本对比（后续）

## 13. 同步任务中心
状态：queued / running / completed / failed / cancelled。
支持查看任务详情、进度、错误和重试入口。

## 14. 导出窗口
- 导出范围
- 字段选择
- 格式：XLSX / CSV / JSON
- 文件目录
- 导出完成后“打开所在目录”

## 15. 授权信息页
只展示 License：
- 授权 ID
- 有效期
- 可使用系统
- 可使用事项
- 设备额度
- 导出/自动同步能力
- 更新授权密钥

## 16. 设置页
只保留桌面工具需要的设置：
- 更新检查
- 默认分页大小
- 默认导出目录
- 并发任务数
- 审计日志保留期
- 本地数据库位置（只读显示优先）
- 关于/版本

## 核心交互规则
- 软件无用户账号登录。
- 每个业务系统拥有独立登录态。
- 查询前必须具有有效业务系统会话。
- 会话失效后中断当前远程请求，不丢失查询条件。
- 查询与本地回流是两个明确动作。
- 长任务始终进入 Task Engine。
- 删除、覆盖、大批量导出等高影响动作必须明确确认。
