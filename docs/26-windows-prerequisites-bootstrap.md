# Windows 运行环境自动补齐安装器

> 历史方案记录（2026-11-11 已停止作为默认交付）：用户反馈体积过大，且 Win7 实际日志已确认可通过使用系统自带 CLR2 / .NET3.5 解决安装检查启动问题。当前 `package:universal` 生成不包含系统补丁的小型双内核通用包，不再调用本文的自动补装流程。当前构建及交付请参见 [Windows 通用安装包](25-windows-universal-compatibility.md)。以下仅保留先前方案和诊断记录。

## 范围

这是本地 1.0.21 通用测试包的安装器改进，应用内两套 Electron 组件不变。用户运行同一个 EXE，安装器检测缺失环境并调用随包提供的微软官方离线安装程序；无需在旧电脑上联网下载。产物位于 `release/1.0.21/universal-environment/`，不发布线上更新。

运行前置程序使用 NSIS 原生插件，不依赖尚未安装的 .NET，也不调用 PowerShell、批处理或修改脚本执行策略。

## 检测和顺序

1. 仅接受 64 位受支持系统，按系统选择现代或 Win7 兼容运行环境。
2. Windows 7 原版 7600 缺少 SP1 时，先安装 KB976932，重启后继续。
3. .NET 检查读取两个注册表视图的 Full/Release，最低为 4.6.2（394802）。不再只凭 .NET4.0 的 Full/Install 判断就绪，因为更新宿主调用了更新的 .NET API。
4. Win7 SP1 缺少足够版本的 .NET 时，同时检查 CBS 已安装或已替代的系统支持包；先补齐更新服务栈 KB4490628、SHA-2 支持 KB4474419，再安装 .NET4.8。识别若干后续服务栈版本，避免已更新系统重复准备。
5. 每阶段就绪后才进入应用组件安装；前置组件失败不会调用应用卸载或覆盖现有应用。

SP1、SHA-2 阶段成功后先重启再继续；其他阶段尊重安装结果的重启要求。所有组件传入 `/norestart`，前置程序不强制重启，提示用户保存工作并手动重启。

## 权限、验证与续装

- 交互安装显示一次缺项和系统变更说明，确认后自动执行后续准备；微软组件按需触发 Windows 管理员授权。用户取消授权时停止并记录日志。
- 只有经过校验的固定本地组件路径会交给 ShellExecuteEx；只提升微软系统组件，应用安装仍保持原用户身份。
- 构建时校验下载大小、固定摘要、微软有效签名；MSU 验证其内部更新目录的微软签名。安装前再次校验整包 SHA256，Windows 更新安装器再验证 MSU 签名。
- 重启前把原安装器复制并核对到 `%LOCALAPPDATA%\DataFusionInstaller\1.0.21\Setup.exe`，在当前用户 RunOnce 登记续装。安装阶段写入同版本状态键。
- 重启登录后重新检测实际环境；上个阶段仍缺失则停止，不反复重装和形成重启循环。环境就绪或失败时移除本程序自己的续装项。
- 静默安装缺少环境时，默认返回 32，防止普通静默更新意外修改系统。管理员明确指定 `/S /INSTALLPREREQUISITES` 后才允许自动补装；需要重启返回 3010。
- `/CHECKOS` 只输出检测结果，不安装任何组件、不登记续装。

日志在 `%LOCALAPPDATA%\DataFusionInstaller\1.0.21\prerequisites.log`，包含缺项、阶段、摘要、原始组件退出码；.NET 安装日志位于同目录。应用自身的导出备份与日志路径不变。准备缓存保留，便于重试和排查。

## 构建和验收

`resources/windows-prerequisites.json` 登记官方来源和摘要。把完整的官方文件放入 `.tmp/windows-prerequisites/` 后执行 `npm run package:universal`，缺文件、摘要错误或签名不符会停止构建，不会降级成不带组件的安装包。两个内部应用组件仍按文档 25 的顺序构建。

运行 `npm run test:prerequisites` 执行真实 NSIS、哈希和进程等待回归：使用隔离的无害测试 EXE 模拟微软组件及重启结果；注册表和续装入口使用专用测试键，不写真实 RunOnce、不执行系统更新、不重启当前电脑。覆盖准备顺序、已有环境跳过、未授权静默调用、摘要错误、安装失败、成功后重新检测、重启续装与失败停止重试。

Win7 7600 上的真实微软组件安装、重启恢复、原系统登录与回流尚待实机验收。自动准备不能保证修复所有系统损坏、证书链异常或被管理员策略禁止的安装；这些情况停止并保留明确日志。不会绕过微软签名检查或关闭系统防护。
