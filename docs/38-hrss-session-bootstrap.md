# 广东人社会话识别与后台初始化

2026-11-27用户反馈麒麟业务1.1.14在登录后门户首页及子系统打不开，日志显示 `SESSION_EXPIRED`。截图不足以判断页面连接失败的具体网络原因，不能把本次代码缺陷直接认定为现场全部故障的根因。本次仅修改代码、测试并提交，不发布自动更新，不改变用户运行中的1.1.14。

## 已确认并修正

- 缺少就业、扩岗或创业培训的独立凭据，返回“尚未取得对应会话”，不误判为整个平台过期；门户Cookie和已保存的其他子系统数据保留。仍须真实只读验证才能显示已登录。
- 三类凭据分别维护代次；排队或在途旧请求、旧浏览器观测不能清掉或覆盖新登录信息。
- 先解析JSON，不因Content-Type为text/html直接清会话。非预期HTML、错误JSON和网络异常保留凭据，记录脱敏分类。HTTP401及已有明确业务失效响应继续执行对应凭据清理；源补贴Axios明确把HTTP403作为权限拒绝，公共Access-Token族据此保留。独立模块没有相同证据，暂保留原规则。
- 日志增加固定原因枚举、凭据家族、401/403状态及安全网络原因码；不输出Cookie、Token、SSO参数、响应体或任意原始异常。
- 人社独立浏览器分区使用直连，页面和主进程接口统一规范化中文User-Agent产品名，保留实际Linux/ARM及浏览器版本。不修改其他系统的代理，不伪装Windows，不关闭证书检查。

## 门户登录后自动初始化

用户无需为了取得凭据逐个点击子系统。主页面成功进入原门户 `/portal/template/system.html` 后，使用同一隔离分区的隐藏页面加载原门户，从当前账号真实的Vue菜单读取入口，不猜系统地址或单点登录参数。初始化串行执行，每次门户登录最多初始化三类缺失会话，不创建回流任务、不保存列表业务记录；原页面自身的初始化请求仍可能自然发生。

外部类型入口严格沿用原 `toIndexPage` 的prefix/url公式和 `indexTool.getSsoTokenStr()`，且限定为已声明子系统根页或index首页，拒绝同一命名空间下的退出API或业务受理页。内嵌类型只选择真实菜单中的查询叶节点，使用原 `indexTool.openTabMenu` 生成iframe；缺prefix时先用原 `systemInfos[sysCode].url` 补齐。仅接收已声明的原站就业、补贴、WGBT及ZXZJ路径；不打开受理、审核或审批表单。真实菜单没有提供入口时不猜测、不扩大账号权限。异步菜单尚无目标时继续有界等待；失败后允许下次门户导航补试一次，每轮登录最多两次，不触发循环重试或整个平台退出。日志区分门户和子系统未就绪。

Access-Token既监听原REST业务请求，也监听原静态资产已声明的两个 `api/security/users/current/loginResponse` 身份请求；不主动调用猜测身份接口。扩岗凭据须来自实际成功的子系统请求观测，不能仅依靠任意门户Cookie；培训只读取浏览器实际会发送到其源页面的Cookie，且需存在原站hz_zxzj标识。这些材料只是待验证会话，不作为业务鉴权成功证据。

可见门户不导航、不被抢焦点。关闭原系统页、进入登录页或退出应用会取消后台初始化；退出登录及应用关闭先等待其收尾。隐藏页面销毁前，仅对其私有WebContents启用CDP网络阻断，并登记其已停止状态，防止子iframe的unload退出请求撤销刚取得的凭据。用户可见原页面的主动退出不受此阻断影响。

## 验证与限制

合成测试覆盖缺子系统凭据的跨重启保留、旧请求代次、HTML响应、HTTP403权限拒绝、真实失效、安全日志、原门户菜单提取及串行初始化。原生测试通过独立临时配置、临时TLS证书和进程内DNS映射，把固定原站主机指向本机HTTPS夹具；不使用真实账号或会话。测试区分直接页面和原门户iframe菜单，检查三类初始化、原可见页保留、隐藏页释放及无退出请求。临时证书仅由该测试分区按完整指纹信任，不进入产品或系统证书库。

曾用只销毁BrowserWindow的方案，在真实Electron中发现子iframe仍发unload beacon；加入目标级网络阻断后才通过。协议拦截夹具不能完整覆盖webRequest，因此最终使用真实loopback HTTPS。

运行：`npm run test:hrss:bootstrap`；本机已备Electron22运行目录时可执行 `node scripts/run-ui-smoke.mjs hrss-background-session --legacy`。该原生夹具依赖Python cryptography，临时监听127.0.0.1:443；端口占用时应停止测试，不修改已有服务。
