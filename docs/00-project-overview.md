# 00. 项目总览与产品基线

## 1. 项目定位

数据融合助手是一个基于 Electron 的本地桌面工具，用于帮助业务人员在其本人有权限访问的业务系统中完成数据查询、回流、本地留存、去重更新、历史追踪和导出。

本项目不是后台管理系统，也不建设业务数据中心服务器。桌面端是产品主体，业务数据默认只在用户本机流转和存储。

## 2. 核心用户路径

```text
启动应用
  ↓
密钥激活
  ↓
进入工作台
  ↓
选择业务系统
  ↓
检查该系统登录状态
  ├─ 未登录 → 在应用内完成原业务系统登录
  └─ 已登录 → 继续
  ↓
选择业务事项
  ↓
根据事项 Schema 生成查询条件
  ↓
执行原业务系统查询
  ↓
预览结果
  ↓
同步到本地
  ↓
新增 / 更新 / 无变化 / 历史版本
  ↓
本地检索 / 查看详情 / 导出
```

## 3. 已确定的产品原则

1. 应用本身不建设用户账号体系，只使用授权密钥激活。
2. 密钥决定可使用系统、事项、有效期、设备数、导出能力、自动同步能力等。
3. 用户必须在应用内登录对应业务系统后，才能查询该系统数据。
4. 登录后由对应系统插件管理 Token、Cookie、Session、CSRF Token 等认证信息。
5. 原始认证凭据不直接暴露给 Renderer 页面。
6. 只处理当前业务账号本来有权查看的数据，不设计绕过权限、破解权限或越权访问能力。
7. 所有业务数据默认仅存本机，不上传授权服务器或更新服务器。
8. 每个业务系统独立插件化；每个业务事项拥有独立查询 Schema、字段映射、唯一键和同步策略。
9. 本地数据不是单纯覆盖，而是区分新增、更新、无变化，并保留关键历史版本。
10. 公网服务器仅承担授权、版本、更新包和插件更新职责，不接触业务数据。

## 4. 产品边界

### 本地桌面端负责

- 授权密钥校验
- 业务系统登录
- Token / Cookie / Session 会话维护
- 查询条件生成
- 原系统接口调用
- 分页查询
- 数据预览
- 本地 SQLite 存储
- 去重和更新
- 历史版本
- 本地搜索
- Excel/CSV 等导出
- 同步任务
- 日志
- 插件加载和更新

### 公网服务负责

- License 激活/校验
- 设备绑定/解绑（后续）
- License 吊销（后续）
- 主程序版本清单
- 插件版本清单
- 更新包下载

### 公网服务不负责

- 不接收业务查询结果
- 不接收业务系统 Token
- 不作为业务数据中转
- 不建设集中业务数据库

## 5. 第一阶段目标

第一阶段优先搭完整底层，不接真实系统：

- Electron 主进程
- React Renderer
- Preload 安全桥
- IPC 协议
- Plugin Registry
- AuthAdapter / Session Manager
- Business Matter / Query Schema
- SQLite Repository
- Sync Engine
- Task Engine
- Mock 系统插件
- License 接口
- 更新接口预留

完成后再选择一个真实业务系统作为第一个正式插件。
