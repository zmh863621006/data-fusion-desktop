# 1.1.16 发布记录

构建源码冻结于 `33343634992b7b180b3ebf11a74fadd9565f29dc`。标准深圳部署，后台 `https://193.112.96.168`、配置修订号 1；最低基础版本继续为 1.1.0。根目录历史 `package.json` 版本保持，业务及基础版本通过构建参数明确指定为 1.1.16。

2026-11-27（Asia/Shanghai）按用户确认，通过后台正常登录、上传草稿和密码复核发布五个业务通道及四个完整安装包。没有直接修改发布数据库或手工覆盖 OSS 清单，完成后退出管理员会话。

现有固定基础包用户通过原 OSS 入口更新业务 ASAR；下次完整启动或主动检查并确认重启后加载新版，不强制关闭使用中的客户端。旧安装更新方式获取本次完整基础包；新安装的基础环境与内置业务均为 1.1.16。安装器前置窗口修复随完整安装包提供，ASAR 更新不替换已经安装的外层安装器。

## 本轮变化

- 人社门户登录后按原站菜单初始化可用子系统会话，隐藏、串行、限量执行，保留可见门户首页；局部子系统缺少凭据或无权限不再使整个门户失效。加入代次保护，避免旧响应清除新会话。人社分区直连与代理隔离继续保持。
- 深圳一体化十项接入经办列表、详情及办理过程；合并来源的两项补贴仍保留独立授权入口，共用规范化存储，避免重复统计。原系统及工作台支持 F12 开发者工具。
- 房屋租赁、一窗综合、深圳一体化、全员人口增加工作台账号配置；本地加密保存和回填，不代填验证码、证书口令或 PIN，不自动提交。系统密钥环保持。
- 应用显示“深圳市房屋租赁”“深圳市一窗综合”，后台显示对应完整名称；系统 ID、授权及历史保持。三处使用核实的原站静态图标，其余使用明确的业务图形；图标随包提供。
- Windows 通用安装器完成准备后隐藏前置进度窗口，等待实际安装器结束，保留退出码及临时文件生命周期。
- 断网启动使用已校验的本地版本，进入应用后安排一次 10 秒补查；人工检查成功会取消补查，检查请求合并，不在正在执行任务时强行退出。

账号字段依据及真实站点验收边界见 [账号配置、名称与图标](40-system-credentials-names-icons.md)；会话初始化见 [人社会话](38-hrss-session-bootstrap.md)；安装与补查见 [更新修复](39-installer-handoff-and-startup-recheck.md)。

## 后台变更

以当前线上文件为基线，仅部署三个文件：`app.mjs` 增加四行受限名称迁移，两个事项目录仅修改 `name/clientName`。迁移只覆盖两个系统的已知旧默认名称，保留管理员自定义名称与停用状态。没有部署本地分支的其他后台功能。

正常停止原后台容器前后保留一致性 SQLite 备份，核对全部 24 张表：只改变两个 `systems.name` 字段，其他行与字段完全一致。其余 47 个文件、容器镜像保持；HTTP 与 HTTPS 健康检查均为 200。

- 五路业务包核对源输出字节、目标、版本、最低基础版本、后台配置及敏感文件排除。未包含测试数据库、模拟人社记录、凭据、原始 HAR、私钥或原生二进制。
- Windows 最终通用 EXE 逐层解包、固定壳、图形组件、PE 版本、Fuses、`/CHECKOS`、中文导出备份恢复、7 项安装器交接及 4 项身份隔离检查通过。

- 三个 DEB 独立解包逐字节核对、架构、权限、root 所有权、GNU tar、Installed-Size、官方 Electron ZIP、固定壳及内置业务校验通过。生产 1.1.0 与本次 1.1.16 更新器字节一致；三路真实 1.1.11 → 1.1.16 协议的下载、待更新阻断、切换、二次启动、离线与 8 个数据哨兵保留通过。
- 发布后九个产物均从真实 OSS 完整下载，长度与 SHA256 逐项匹配；五路公开业务清单、四路受设备授权保护的安装包清单 RSA 签名验证通过。四路新包 Range 下载、稳定入口跳转及旧 1.1.0 下载链接均保持。
