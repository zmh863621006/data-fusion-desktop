# 深圳一体化登录入口核对

2026-11-27根据用户确认，将深圳市一体化经办平台的登录入口改为 `https://61.144.226.148:8001/cas/login`，不再把 `/TRANS/zhsl/home` 当成登录地址。系统仍使用独立持久浏览器分区，保留原站标签页，由原网页处理登录及跳转。源码提交为 `0ff88ab`，修改已进入本地1.1.13通用测试包，未发布自动更新。

两份补充HAR分别记录登录首页和切换账号密码页面。CAS入口先显示密钥验证页，通过本机证书驱动探测及证书列表接口处理密钥；账号密码页面当前分支将密码进行Base64处理后再以SM2加密提交，备用分支才使用MD5。助手沿用原站页面，不自行重放这些登录操作。

这些HAR没有真正提交账号密码后的登录成功跳转、业务首页、只读身份接口或完整Cookie记录。`/cas/getIsOpenNationalEn` 仅提供登录前加密配置，不能作为登录成功证据。因此本轮不新增猜测式登录检测；需要成功首页及只读身份接口的抓包，才能可靠判断会话有效、失效及恢复后的首页入口。当前已有Cookie也只表示待验证，不显示为已登录。

相关目录及原系统标签页回归测试、类型检查通过；最终安装包中两个Windows内核均核对包含CAS地址。仅离线分析HAR，没有向该系统提交账号密码或调用业务接口，原始凭据不进入源码、日志或Git。
