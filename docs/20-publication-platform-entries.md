# 政务双公示平台登录入口

政务综合信息系统的“回流数据”页在导出按钮旁提供两个报送入口：

| 按钮 | 平台 | 入口 |
| --- | --- | --- |
| 报送南山双公示 | 南山区公共信用信息服务与监管平台 | `https://nsxy.szns.gov.cn/credit/#/home` |
| 报送省行政执法双公示 | 广东省行政执法信息公示平台公示管理系统 | 用户提供的 `xtbg.gdzwfw.gov.cn/orgDev/rz/index.html` 登录URL，保留appid、agentid、redirect_uri、state及workbench路由 |

当前只打开登录页面，不实现任何报送接口、上传、自动导出、页面填值或表单提交。点击不传批次、事项、企业信息或原系统凭据，只把固定平台标识传入主进程；主进程根据内置目录选取入口，拒绝任意URL。登录、验证码及后续页面操作由用户完成。

复用应用内原生标签页容器，两个平台各有独立浏览器分区，与政务原系统和彼此隔离。再次点击打开已有标签，不覆盖已登录页面、筛选条件或历史。后退、刷新、关闭和切换保持原交互。公示页面提供“返回回流数据”，仅隐藏当前原生视图，不销毁页面；当前批次与搜索条件保留。未新增业务组件、额外授权项或后台配置。

入口跟随现有 `government-info` 授权。受信IPC逐次校验权限，重新激活公示标签也校验其所属系统；渲染层在政务授权失效或撤回时隐藏标签并退出原生视图。公示页没有业务插件会话探测或自动凭据填充，也不注入/保存业务SessionStorage。持久浏览器分区保留平台自身支持持久化的Cookie等内容，实际登录有效期由该平台控制；本次没有新增跨应用重启的登录恢复探测。

固定目标和所属授权见 `src/core/publication/platforms.ts`，原生页面承载见 `src/main/login-tab.ts`，IPC见 `src/main/ipc.ts`，按钮及导航见 `src/renderer/src/App.tsx`。

隔离验证覆盖主进程受信/授权边界、任意URL拒绝、页面复用、独立关闭、保留业务标签和表单、批次与搜索条件保留、打开失败提示及授权撤回；桌面UI在1440×900和1180×720检查按钮尺寸与布局。测试使用本机虚构页面和数据，不登录真实公示平台、不上传数据或消耗付费查询额度。实际平台认证仍需用户本人完成。

## 1.0.20 南山模板纠正（2026-11-09，仅内部使用）
