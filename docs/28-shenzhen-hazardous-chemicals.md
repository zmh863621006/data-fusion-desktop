# 深圳危化品系统接入（1.0.24，本地测试）

应用内名称为“危化品管理”，标识 `shenzhen-hazardous-chemicals`。原系统为深圳市危险化学品安全生产风险监测预警系统，登录入口为 `https://szwh.yjgl.sz.gov.cn/iHome/#/login`。目录含新领、延期、变更、注销及第三类非药品类易制毒化学品经营备案5项，许可和备案分别分组。

## 会话及接口

依据用户2026-11-16提供的两份HAR和完整页面前端代码。HAR原文、真实token、人员证件和接口响应不加入仓库或安装包。

原页面将 `Authorization`、`userId` 保存于 sessionStorage。登录页沿用应用内独立标签页和持久浏览器分区；主进程只读取这两个指定键，将 Authorization 作为 DataBus JSON 请求体的 `CONSUMER_ID`。两者经现有加密会话存储恢复，恢复后先以一条已办列表请求验证；HTTP200的网关 `008899` 拒绝必须判为会话失效。Renderer只接收状态，不接收凭据；配置账号密码使用既有受限填充机制。

所有请求固定发送到 `https://szwh.yjgl.sz.gov.cn/DataBus/exchange`，只允许以下 SERVICE_CODE：

| 用途 | SERVICE_CODE后缀 | 规则 |
| --- | --- | --- |
| 已办业务 | `ApprHandleLog.selectHandleDoneApprProcessList` | `type=1`、事项名称/编码及分页，筛选 `lczt=流程结束` |
| 已制证 | `ElectronicRouting.getElectronicLicenseList` | 用已办 `sblshShort` 作为 `bizNum` 查询并再次精确匹配 |
| 制证数据导出列表 | `ElectronicRouting.certificationDataReportList` | 读取JSON列表，按 `sblshShort` 与本次流程结束集合关联 |

此流程不调用原站Excel导出、制证、签发、上报、附件或保存接口。分页数量变化、结构异常、取消或内容冲突会终止本次结果；不会将获取了一部分的结果保存为成功批次。

原站导出列表176条对应170个流水号，其中6条仅序号number不同。仅这种内容一致的重复会被合并；同一流水号的导出内容不一致时停止任务并提示核对。原站制证操作员的身份信息、authCode、PDF URL不写入台账。

## 字段与缺项

| 本地双公示字段 | 来源 |
| --- | --- |
| 相对人名称、信用代码、法人 | `administrativeName`、`unifiedSocialCreditCode`、`legalRepresentative` |
| 法人证件 | `legalRepresentativeType`、`legalRepresentativeNumber`；存在号码时才输出类型 |
| 案件名称 | `caseName` |
| 证书名称、许可编号 | `licenseName`、`licenseNumber`；缺项时只用关联照面的 `ZZMC`、`ZZHM` |
| 许可决定日期 | `permissionDecisionDate`，不以FZRQ、agentTime或已办time替代 |
| 有效期自、至 | `startTime`、`endTime` |
| 许可内容 | `licenseContent`；普通许可缺项时可用关联照面的XKFW |
| 决定文书名称、文号 | 仅明确为通知书/决定书时映射相应名称和号码；普通许可证号不充当决定书文号 |
| 许可机关、来源单位 | 用户确认“深圳市南山区应急管理局”，代码 `11440305MB2D288348` |

普通许可的“普通”“依职权”来自原页面固定输出。注销和备案的许可类别、处理结果、当前状态保留待核对；原站注销记录同样返回“予以许可”，该原值留作依据，不直接用于许可处理结果。52条注销样本的许可内容为空，不合成正文。备案暂无实测数据，保留目录和缺项规则。

企业信用代码按现有格式及校验位校验；无效9位组织代码保留在依据里，不能作为18位信用代码输出。缺失企业信息进入既有本地/后台企业补全流程，后台库未补齐时才按既有付费开关、额度及授权规则查询供应商；原系统已齐全的企业不额外查询。

日期控件按显式许可决定日期筛选，默认留空回流全部流程结束数据。日期明确的记录照常写入选定批次，缺少可核对决定日期的记录在回流任务中提示条数。全量回流保留这些记录供核对。

## 导出和授权

接入现有省执法24列及南山31列Excel模板、缺项确认、整行红色和批注、固定应用导出目录及文件夹链接。公示平台入口仍只打开原站登录，不提交数据。危化品使用独立公示标签ID及浏览器分区，检查其自身系统权限，避免借用政务权限。

新领、延期、变更、注销使用南山模板导出时，行政许可决定文书名称为“危险化学品经营许可证”，行政许可决定文书号取台账许可编号。缺少许可编号时按南山模板缺项规则提示。

危化品管理的南山导出保留法定代表人姓名，法定代表人证件类型和证件号码两列留空。

后台增量注册系统及5事项，保留停用标记和已有客户授权。需管理员明确追加权限。本次已通过正常范围调整API给本机原在线授权追加5项，并核对其他授权及原功能开关未变；正常签名刷新返回新权限。前端动态目录可直接显示新系统，不另部署后台页面。

## 验证与交付

813项桌面自动测试、116项后台测试、类型检查及两种尺寸实际UI烟测通过。真实只读抽样每个有数据的事项各取1条，四项均成功关联；当前已办数量为新领82、延期14、变更25、注销51、备案0。该抽样没有保存真实业务记录或调用企业付费查询，不能代替用户逐条验收。

后台先以无网络、无生产数据挂载的候选容器验证，再备份SQLite并窄部署实际app.mjs及新目录JSON。既有客户、授权、企业、版本发布等保护表在目录部署前后摘要一致；后台健康及登录/验证码接口通过。本机授权随后由正常API单独追加权限。备份目录为 `/var/lib/data-fusion/backups/hazchem-20261116/`；本地脱敏结果位于 `private/deploy/hazchem-20261116/`。

Windows仅交付本地1.0.24兼容通用测试包，不发布自动更新。现代程序已实际隔离启动，最终包两套运行环境、图形组件、原生导出保全程序、安装分流及文件完整性校验通过；此次没有在Win7实机安装该新包，也没有替换用户本机正式应用。产物和SHA256见 `release/1.0.24/universal/universal-manifest.json`。
